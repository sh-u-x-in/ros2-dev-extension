# 助手版本控制规范(VERSION-CONTROL)

> **性质:规范冻结文件(Normative / Frozen)。** 本文件定义常驻助手(Python 服务端)的
> 扩展版本控制契约。格式与语义一经发布即冻结:未来任何更新**只许追加,不许改名、
> 不许重排、不许改语义**;确需变更须在「修订记录」追加条目并同步全部契约测试。
> 落盘日期:2026-10-20。首版:0.0.5(内部测试)——本扩展第一个带版本控制的助手版本;
> 0.0.3 及此前版本的助手/锁文件没有版本字段(按本文「旧格式」处置)。

## 1. 锁文件格式(冻结)

路径 `/tmp/rde_param_helper.lock`(与 socket 同级的固定全局路径,TS 侧
`param-helper-protocol.ts` 与 Python 侧 `kernel.py` 常量对锁)。flock 胜者写入,
**一行、空白分隔、恰好四字段**:

| # | 字段 | 含义 | 语义 |
|---|------|------|------|
| 1 | `pid` | 服务端进程号 | 十进制整数 |
| 2 | `epoch` | 服务端启动时刻 | Unix 秒(整数) |
| 3 | `ticks` | 进程启动时刻 | 内核时钟滴答开机起计(`/proc/<pid>/stat` 第 22 项);**pid 复用防护**:杀前必须与 `/proc/<pid>/stat` 现读值对账,不一致=pid 已换人,绝不下手 |
| 4 | `version` | **拉起该服务端的扩展版本** | `N.N.N`(严格三段十进制);占位 `"0"`=未知/未传(按「最旧」处置) |

- 字段 4 的传输通道:TS spawn argv `--ext-version N.N.N`(经 `param_helper.py::_ext_version_arg`
  → `main(ext_version)` → `server.acquire_lock(ext_version)`)。**不许改走 spawn env**
  (CommandRunner 的 options.env 是整体替换,会抽掉 ROS env)。版本自身不得含空白
  (服务端只取首个空白分隔 token,其余丢弃)。
- 追加规则:未来新增字段**只能追加在第 4 字段之后**;所有读取方必须容忍「尾部字段缺失」
  (三字段锁=0.0.3- 遗留,合法输入)。

## 2. 版本比较规则(冻结)

版本串 = 严格 `N.N.N` 三段数值比较(非字典序;`0.0.10 > 0.0.9`)。解析规则:

| 锁文件版本(第 4 字段) | 我方版本 | 裁定 |
|---|---|---|
| 可解析,严格**小于**我 | 可解析 | **杀旧拉新**:先 pid 探活(`kill(pid,0)`)→ `killForeignServer`(内含 ticks 对账)SIGKILL → 走连接被拒路径 spawn 本版本助手 |
| 可解析,**等于**我 | 可解析 | 共享(connect-first 照旧) |
| 可解析,严格**大于**我 | 可解析 | **让位共享**(绝不杀;旧客户端连新服务端只共享) |
| 不可解析 / `"0"` / 字段缺失(三字段旧锁) | 可解析 | 视为最旧 → 杀旧拉新 |
| 任意 | 不可解析 / 未注入 | **治理禁用**:绝不杀,connect-first 照旧(安全态;组合根 `extension.ts` 注入 `setParamHelperExtensionVersion`)

## 3. 多客户端语义(冻结)

共享一个远程的多个客户端可能版本不同(典型:扩展更新瞬间,旧窗口=旧扩展宿主仍在跑)。

- **只有「新」杀「旧」,单向淘汰。** 因此不存在杀拉震荡:0.0.5 杀掉 0.0.4 服务端并拉起
  0.0.5 后,旧窗口的 socket 断开 → 旧客户端走既有自愈(重连优先)→ 连上 0.0.5 服务端 →
  hello proto 相同 → **共享**,不会 spawn 自己的旧版本。
- 替换瞬间的代价(已知且接受):其他客户端的在飞请求随 socket 断开全部失败
  (`failAllPending`),客户端自愈重连;状态页短暂离线一拍后恢复。
- flock 仲裁保证「杀后拉新」竞速下全局仍恰一个服务端;败者自动退出(exit 0),客户端直连胜者。

## 4. 与 hello 握手的分工(冻结)

- **hello proto(`rde-helper/1`)+ 环境指纹 = 线路协议层**,deny 级:协议/环境不匹配拒绝服务。
- **锁文件第 4 字段 = 进程身份层**,治理级:决定「该由哪个版本的扩展拉起服务端」。
- 扩展版本号**有意不进 hello**:服务端不需要它(裁决全在客户端),而把它放 hello 会让
  「新服务端拒旧客户端」——旧客户端拿到 deny 只能熔断,没有任何恢复路径。锁文件方案下
  旧客户端永远能连上新服务端共享,体验平滑。
