# config/write 配置动作规格 — 文件角色 × 包类型

> 状态:规格稿(2026-09-03 17:03 建档,待确认后作为重构契约)
> 目的:先明确「每个文件角色在各包类型下到底改哪个文件、加什么、怎么判幂等」,再据此修正实现(当前实现有偏差,见 §4 修正清单)。
> 依据:设计/新功能/01;ROS 2 安装事实——ros2 run 在 <prefix>/lib/<pkg>/ 找可执行(X_OK);ros2 launch 在 <prefix>/share/<pkg>/launch 找文件;ament_python 的 console_scripts 产 lib/<pkg>/<cmd>(见 config/run与launch执行机制研究 §5.2);ament_index 需要包被安装。

## 0. 一句话总则

「让文件被 ROS 2 构建/运行找到」= 把该文件(或其声明)装进**该包类型规定的安装位置**。
三种包类型的「配置入口文件」:ament_cmake / cmake → CMakeLists.txt;ament_python → setup.py(全部为整文改写)。

## 1. 动作矩阵

| 文件角色 | ament_cmake | cmake(纯) | ament_python |
|---|---|---|---|
| **launch** (launch/*.launch.py\|xml\|yaml) | CMakeLists 追加 install(DIRECTORY launch DESTINATION share/${PROJECT_NAME}) | 同上(注:纯 cmake 的 ros2 可见性还需自身 install package.xml 到 share/,超出工具范围,建议转 ament_cmake) | **setup.py data_files 加 (os.path.join('share','<pkg>','launch'), glob('launch/*.launch.py'))**(整文改写;glob 需 import glob) |
| **msg/srv/action** | CMakeLists:①find_package(rosidl_default_generators REQUIRED) ②文件行**插进既有** rosidl_generate_interfaces(...) 块(无块则新建,文件行 "msg/X.msg") ③ament_export_dependencies(rosidl_default_runtime);package.xml:buildtool_depend rosidl_default_generators + exec_depend rosidl_default_runtime + member_of_group rosidl_interface_packages(**插到 </package> 前**) | 不支持(rosidl 宏属 ament 生态,提示用 ament_cmake) | 不支持(ament_python 无 rosidl 生成,提示) |
| **cpp** (src/*.cpp) | 完整链:①add_executable(t src/x.cpp) ②find_package(<dep> REQUIRED) ③ament_target_dependencies(t <dep>) ④install(TARGETS t DESTINATION lib/${PROJECT_NAME});package.xml 加探测依赖的 <depend> | add_executable + **target_link_libraries**(非 ament 宏)+ install(TARGETS … lib/<pkg>);依赖 find_package | 不支持(py 包内 cpp 属扩展场景,超出 v1) |
| **python** (scripts/*.py 等) | install(PROGRAMS <rel> DESTINATION lib/${PROJECT_NAME})(+可执行位) | 同上 | **console_scripts**:entry_points={'console_scripts':['name = module:func']}(整文改写 setup.py;幂等按条目名)。模块入口 module 用交互询问(name=module:func,现状已做) |
| **shell** (*.sh) | install(PROGRAMS … lib/<pkg>) + chmod +x(非 Win) | 同上 | **不作为 ros2 run 可执行**(console_scripts 需 python);如需随包分发 → data_files 装 share/<pkg>/scripts 仅作资源(v1 提示手动) |
| 其他/未知 | 提示不支持 | 同 | 同 |

## 2. 写回形态(每种包类型不同)

| 改动文件 | 写回形态 | 锚点/位置 |
|---|---|---|
| CMakeLists.txt | 片段**追加** | 优先插到 ament_package()/ament_export_* 之前(若存在),否则文件尾;install/add_executable 顺序不敏感,尾追加语义安全 |
| CMakeLists.txt(rosidl 已有块) | **原位插入文件行**(块内) | rosidl_generate_interfaces( 开括号后、块内首个 ) 前;rosidl 只能一次调用,不能重复建块 |
| package.xml | **锚点插入**(</package> 前) | 绝不能尾追加(会把依赖写在根闭合标签之后,XML 非法——当前实现有此 bug) |
| setup.py | **整文改写**(replace) | console_scripts 列表/键补全/setup() 尾部参数;data_files 条目同理;改完用 parseSetupPy 复核 |

## 3. 幂等判定键(复用 parse)

- CMakeLists:parseCMakeLists — installs 是否含 (DIRECTORY\|PROGRAMS, 目标);executables 是否含目标名;dependencies 是否含 rosidl_default_generators;文本含 fileRel;
- setup.py:parseSetupPy — consoleScripts 是否含条目名;dataFiles 是否含 share/<pkg>/launch 目标;
- package.xml:文本含对应 tag(rosidl_default_generators/rosidl_default_runtime/rosidl_interface_packages/<depend> 名)。
