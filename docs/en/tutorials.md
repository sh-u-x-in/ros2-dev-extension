# Tutorials and Walkthroughs

## Built-in Walkthrough

Run **ROS2: Show Getting Started** from the Command Palette (shown automatically after install) for a guided tour of the main features.

## Learning Path

1. [Usage](usage.md) — commands, the package contents sidebar and smart build
2. [IntelliSense](intellisense.md) — message completion/navigation, xacro and launch navigation
3. [Test Explorer](test-explorer.md) — discovering and running C++ / Python / launch tests
4. [Configuration](configuration.md) — all 22 settings keys in 7 groups

## Community Resources

The upstream projects this extension derives from have public talks and videos
([ms-iot/vscode-ros](https://github.com/ms-iot/vscode-ros),
[ranchhandrobotics/rde-ros-2](https://github.com/ranchhandrobotics/rde-ros-2)) that cover
shared concepts such as workspaces, colcon and launch files.
