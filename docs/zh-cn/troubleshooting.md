# 故障排查

ROS 2 是复杂系统,问题可能来自多个环节;AI 与 VS Code 生态本身也变化很快。本文提供自我诊断的排查思路与本扩展的常见问题定位方法。

## 输出面板

VS Code 输出面板提供扩展的详细日志:命令面板执行 `Output: Focus on Output View`(快捷键 `Ctrl+Shift+U`),在过滤框旁的下拉里选 **ROS 2**。

查看其中的错误与警告,定位是哪一环节出问题。看不明白时,复制输出留存以便求助;**分享前务必清除敏感信息**。

日志级别说明:右上角级别下拉可切 **Debug / Trace** 获取更细的日志(默认 Info 只记关键事件与状态翻转);环境变量 `RDE_ROS2_LOG_MIRROR`(设为 `console` 或文件路径)可全量落盘,适合无头/长时联测。

## 反馈问题

缺陷与功能请求请到本仓库的 issue 跟踪器提交,尽量附:ROS 2 发行版与安装方式、操作系统、复现步骤,以及输出面板「ROS 2」通道的相关日志。**提交前清除敏感信息**。
