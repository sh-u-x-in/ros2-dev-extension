# Get started with the Robot Developer Extensions for ROS 2

Welcome to the Robot Developer Extensions for ROS 2! This extension supports ROS 2 development on Windows, Linux and macOS.

## Features

* **Automatic ROS environment setup** - the extension detects and configures your ROS 2 environment automatically
* **ROS 2 status page** - start the resident helper with one click to inspect nodes / topics / services / parameters / lifecycle, call services and send action goals directly
* **Run executables & launch files** - run `ros2 run` / `ros2 launch` from the Command Palette or the Package Contents sidebar, with argument templates and memory
* **Build integration** - creates `colcon` build & test tasks automatically and pre-checks install-method and layout issues before building
* **Test Explorer** - discover and run ROS 2 tests, integrated with the VS Code Test Explorer
* **IntelliSense** - completion, hover info and go-to-definition for ROS message files and xacro/launch files, with automatic C++/Python include-path maintenance
* **Package creation wizard** - generate C++ / Python / mixed packages with a built-in dependency picker and name validation
