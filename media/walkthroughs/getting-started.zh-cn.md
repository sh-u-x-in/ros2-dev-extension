# ROS 2 机器人开发扩展入门

欢迎使用 ROS 2 机器人开发扩展！本扩展为 Windows、Linux 和 macOS 上的 ROS 2 开发提供支持。

## 功能特性

* **自动配置 ROS 环境** - 扩展会自动检测并配置你的 ROS 2 环境
* **ROS 2 状态页** - 一键启动常驻助手,查看节点 / 话题 / 服务 / 参数 / 生命周期,并可直接调用服务、发送动作目标
* **运行可执行文件与启动文件** - 从命令面板或「包内容」侧边栏一键运行 `ros2 run` / `ros2 launch`,支持参数模板与记忆
* **构建集成** - 自动创建 `colcon` 构建与测试任务,构建前主动预检安装形态与布局问题
* **测试资源管理器** - 发现并运行 ROS 2 测试,集成 VS Code 测试资源管理器
* **IntelliSense** - 为 ROS 消息文件与 xacro/launch 文件提供补全、悬停信息与跳转到定义,自动维护 C++/Python 的 include 路径
* **包创建向导** - 生成 C++ / Python / 混合包,内置依赖选择与命名校验
